# Күн энергиясы — Ысык-Көл симуляциясы (React + Vite)

## Иштетүү (Çalıştırma)
1. Node.js 18 же жаңысын орнотуңуз (nodejs.org).
2. Папканын ичинде терминал ачыңыз:

```bash
npm install
npm run dev
```

3. Браузерде көрсөтүлгөн даректи ачыңыз (адатта http://localhost:5173).

Даяр версия үчүн: `npm run build` → `dist/` папкасы.

## Бөлүмдөр
- **Симуляция** — күн нуру, панель, инвертор, үй. Убакыт, ай, панелдин бурчу жана булуттуулук башкарылат.
- **Кантип иштейт?** — фотон → электрон–тешик → p–n өткөөл → ток (6 кадам).
- **STEM лаборатория** — документтеги эксперимент (0°, 40–45°, 90°) виртуалдуу түрдө.
- **Экономика жана экология** — өзүн актоо мөөнөтү жана CO₂ эсеби.
- **Сезондор жана метео** — ай боюнча өндүрүш жана оптималдуу бурч.
